# Security policy

Please do not report credentials, tokens, private keys, or personal information
in a public issue.

Use GitHub's private vulnerability-reporting mechanism for this repository when
available. If a credential may have been exposed, revoke or rotate it first and
then provide only the minimum non-sensitive context needed to investigate.

The project uses the public GitHub handle mwilczynska as its maintainer identity.
Do not add personal contact details to bug reports or patches.
