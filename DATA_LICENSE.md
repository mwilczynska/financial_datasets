# Data licensing and redistribution

This release includes generated CSV and Parquet datasets under
data/processed/ and normalized interim CSVs under data/interim/ for research
and backtesting use. There is no blanket license for those data files.

The MIT License applies to original source code only. Published outputs and
derived series may incorporate third-party data whose terms restrict storage,
redistribution, commercial use, or publication. Publishing an output here does
not grant additional rights to upstream data.

Before redistributing or using a file commercially:

1. Check its source manifest under sources/manifests/.
2. Read the corresponding citation note under sources/citations/.
3. Confirm that the source terms permit the intended use.
4. Preserve source attribution and the methodology caveats.

Downloaded source caches under sources/raw/ are not included in the public
release by default. If a future raw file is added, its source terms must be
reviewed separately before it is published.

The project labels reconstructed, estimated, model-derived, and source-spliced
history. Those labels describe methodology; they do not turn modeled values
into observed history or grant permission to redistribute source data.
